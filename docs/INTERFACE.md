# macOS 界面

桌面导航使用 AppKit 的侧栏、列表、工具栏和菜单。窗口材质、玻璃、系统符号、
选择状态与窗口按钮由 macOS 绘制；macOS 26 及之后随系统采用新外观。
内容沿用 WKWebView，统一系统字体、语义颜色、分组列表和紧凑表单。
没有宣传口号或重复的操作说明；锁定、设备限制、安全词及隐私的必要说明保留。

AppKit 从当前窗口外观提供颜色和 SF Symbols，内容随浅色、深色或系统主题变化。
支持 50–200% 文字大小，以及减少动态效果、减少透明度和增强对比度的适配。
这些适配不会修改系统辅助功能偏好。旧桌面缺少外观连接时保留原有网页界面。

## 编辑面板

编辑使用真正的 AppKit sheet。复用同一个 WebView，保留草稿、认证和既有操作；
确认框、文件选择与导出面板附着于当前编辑窗口。
锁定面板采用 480 点宽度的分组表单，全部八种锁定方式均保留。
锁定期间仍可新增屏蔽的网站和应用；其他修改继续经过原有解锁校验。

打开面板时，主窗口的静态画面只暂存在内存中。重挂 WebView 后，其显示层可能
短暂保留主页面的旧帧，因此面板先用不透明背景遮住该帧，再等待编辑布局的动画帧
及 `afterScreenUpdates` 快照完成，之后露出编辑内容。
异步回调绑定本次打开序号，取消旧面板不会误揭开新面板。
绘制超过三秒时恢复主窗口并使用原有网页弹窗，不会留下无法操作的空白面板。

普通保存和认证支持 Return；锁定、启用设备计划及批量导入需要明确确认。
输入法组合、多行文本和持续按键不会意外提交。嵌套取消返回原草稿，错误信息滚动
到可见位置。日期复选框各自关联标签，搜索与筛选器具有可访问名称。

## 文件操作

使用系统保存与打开对话框。导出先写入临时文件，再原子替换目标，失败时保留
原文件和既有权限。WebKit 文件输入保留到选择完成或取消后再清理。
重名导入副本在预览中采用唯一名称并显示原名称；原规则不修改，副本默认停用。
自动启动和设备动作继续需要原有的明确确认。

## 验证

在 macOS 图形会话中构建并运行：

```sh
python3 -B scripts/build.py --qa
python3 -B tests/integration_desktop_interface.py
python3 -B tests/integration_desktop_interface.py --forms
python3 -B tests/integration_desktop_interface.py --transitions
python3 -B tests/integration_desktop_interface.py --files
```

测试使用独立签名的最小应用、临时后台和虚构规则，执行层关闭。
测试应用不携带可启动的后台运行时。`--files` 需要真实确认保存与打开。
汇总与截图保存在忽略的 `build/` 目录；页面截图只包括应用自己的 WebKit 内容，
不包含整个桌面或系统合成的窗口玻璃。

- 主界面：62 项，覆盖五个页面、八种锁定方式、深浅色、200% 字体、菜单与草稿。
- 表单：146 项，覆盖 14 种表单的布局、焦点、标签、键盘、校验及权限状态。
- 文件流程：13 项，真实确认导出与导入，验证取消、嵌套面板、覆盖与失败保护。
- 首帧切换：26 项，实际调用规则与日程页的原生加号，验证延迟帧遮挡、关闭恢复、
  快速重开及绘制停滞时的回退。

完整 VoiceOver 交互、真实系统辅助显示偏好切换、旧版 macOS 和其他机器仍未实机验证。

## 本机更新边界

本次更新仅替换桌面和界面资源，保留已安装的后台与执行器，不包含工作区中尚未
完成的系统保护和设备限制改动。独立的一次性安装入口在用户允许后核验规则、锁定、
设置、安全词、额度和期限保留；普通安装器及其锁定检查没有修改。
睡眠计划保持原状，不在界面测试或安装中触发物理睡眠、注销、锁屏或关机。
当前安装结果以 `build/local-ui-install-proof.json` 为准；公开下载资产没有自动更换。
