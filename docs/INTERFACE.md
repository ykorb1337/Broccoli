# macOS 界面

桌面导航使用 AppKit 的侧栏、列表、工具栏和菜单。窗口材质、玻璃、系统符号、
选择状态与窗口按钮由 macOS 绘制；macOS 26 及之后随系统采用新外观。
内容沿用 WKWebView，统一系统字体、语义颜色、分组列表和紧凑表单。
没有宣传口号或重复的操作说明；锁定、设备限制、安全词及隐私的必要说明保留。

AppKit 从当前窗口外观提供颜色和 SF Symbols，内容随浅色、深色或系统主题变化。
支持 50–200% 文字大小，以及减少动态效果、减少透明度和增强对比度的适配。
这些适配不会修改系统辅助功能偏好。旧桌面缺少外观连接时保留原有网页界面。

右上角仅保留一个“＋”新建菜单，包含“新建拦截规则”和“新建睡眠计划”。
睡眠计划使用床的系统符号，不再以独立月亮按钮呈现。
规则页按“网站与应用”和“睡眠计划”分组，以标题和间距区分，不添加组间横线。
已有其他设备限制时另列一组；搜索仍覆盖全部规则，编辑、锁定与导出保持原有行为。
工具栏不添加侧栏跟踪分隔线，避免在侧栏切换按钮旁出现孤立竖线。

## 文字与休息操作

默认 100% 文字大小下，规则标题使用 14 px，网站和应用数量等说明使用 13 px，状态、时间、分组标题与辅助说明最低 12 px。
原生界面的辅助文字使用不透明的语义配色，提高卡片和背景上的对比度；保持既有文字缩放与主题设置。
每周日程增大列的最小宽度，窄窗口通过横向滚动保留可读文字。

番茄钟、文本验证和等待后的休息期间，规则卡片显示“跳过本次休息”。点击立即恢复拦截，
番茄钟从当前时间开始完整的专注时段；每周日程的独立休息设置同样支持，当前日程结束时照常结束。
文本和等待休息结束后，下次仍需重新验证或等待。操作保留规则锁定、日程、已有使用额度，
由管理权限与设置密码保护。设备睡眠计划仍使用原有安全词放行流程。

## 使用统计图标

原生桌面从本机应用包读取真实彩色图标，按应用标识符、准确路径、可执行文件名及本地化名称匹配。
应用目录在后台扫描；运行中的应用与 Launch Services 补充其他安装位置。重复路径合并，无法确定同名应用时保留首字图标。
图标显示为 20 px，原始 PNG 为 96 × 96，保留透明边缘与颜色，适配 Retina 与 200% 文字大小。
没有应用原图的 macOS 登录组件 `loginwindow` 使用系统用户符号，不显示空的通用应用图框。
搜索、排序与重绘以统计目标匹配图标，网站保留网站符号。此流程不下载远程图标、不启动应用、不写入规则或统计数据。

## 统计工作区（开发中，尚未安装）

统计以 Windows 日视图工作流组织：上方时间线，下方明细与汇总；视觉沿用原生语义配色、
分组表单与系统字体。报表支持保存多个图表、自定义应用/文档/标签系列、折线和柱状、
平均线及表格。标签系列可匹配任一或全部选中标签，系列颜色可独立设置。

图表、表格与 CSV/Excel 导出共用区间数据，截图收集默认关闭。
导出先离开编辑面板，再打开主窗口的系统保存面板，避免把保存窗口附着在即将关闭的面板上。
完整范围、截图、标签管理和安装验收状态见 [功能对照](MANICTIME-PARITY.md)。

## 编辑面板

编辑使用真正的 AppKit sheet。复用同一个 WebView，保留草稿、认证和既有操作；
确认框、文件选择与导出面板附着于当前编辑窗口。
锁定面板采用 480 点宽度的分组表单，全部八种锁定方式均保留。
锁定期间仍可新增屏蔽的网站和应用；其他修改继续经过原有解锁校验。

打开面板时，主窗口的静态画面只暂存在内存中。重挂 WebView 后，其显示层可能
短暂保留主页面的旧帧，因此面板先用不透明背景遮住该帧，再等待编辑布局的动画帧
及 `afterScreenUpdates` 快照完成，之后露出编辑内容。
异步回调绑定本次打开序号，取消旧面板不会误揭开新面板。
绘制超过三秒时恢复主窗口并使用原有网页弹窗，不会留下无法操作的空白面板。

普通保存和认证支持 Return；锁定、启用设备计划及批量导入需要明确确认。
输入法组合、多行文本和持续按键不会意外提交。嵌套取消返回原草稿，错误信息滚动
到可见位置。日期复选框各自关联标签，搜索与筛选器具有可访问名称。

打开弹窗前保存所在页面、滚动位置与焦点。原生面板把 WebView 还回主窗口、恢复
主页面布局后，再恢复位置与焦点；不会在主页面仍隐藏时尝试滚动。
取消、Esc 与关闭按钮均走同一个恢复流程。

## 紧急放行范围

安全词立即放行所有当前生效的设备限制（睡眠、锁屏、注销、关机），包括睡眠前倒计时。
不能提前跳过尚未开始的计划，也不会解除网站/应用规则及其锁定。
每条设备规则只放行到自己当前时段的结束时间；并发的较长规则不会延长较短规则的放行。
弹窗列出当前受影响的设备计划；没有生效的设备限制时，普通放行按钮不可用。
“同时停用当前设备计划及自动启动”是单独的管理选项，勾选后这些计划未来也不再执行。

## 文件操作

使用系统保存与打开对话框。导出先写入临时文件，再原子替换目标，失败时保留
原文件和既有权限。WebKit 文件输入保留到选择完成或取消后再清理。
重名导入副本在预览中采用唯一名称并显示原名称；原规则不修改，副本默认停用。
自动启动和设备动作继续需要原有的明确确认。

测试应用不携带可启动的后台运行时。`--files` 需要真实确认保存与打开。
汇总与截图保存在忽略的 `build/` 目录；页面截图只包括应用自己的 WebKit 内容，

## 本机更新边界

本次更新仅替换桌面和界面资源，保留已安装的后台与执行器，不包含工作区中尚未
完成的系统保护和设备限制改动。独立的一次性安装入口在用户允许后核验规则、锁定、
设置、安全词、额度和期限保留；普通安装器及其锁定检查没有修改。
睡眠计划保持原状，不在界面测试或安装中触发物理睡眠、注销、锁屏或关机。
当前安装结果以 `build/local-ui-install-proof.json` 为准；公开下载资产没有自动更换。

## 截图预览

“应用程序”和“电脑使用”的柱条提供悬浮截图，不占用明细与汇总区域。
指针所指时间决定预览帧；单击后使用同一帧放大，左上角圆形 × 关闭并恢复原焦点。
移开指针、背景单击及 Esc 不会收起放大图。管理锁定与页面切换会清理图片。
屏幕录制默认关闭；当前验证只使用合成图片，尚未安装到正式应用。

## 标签计时与自动标签

“计时…”提供秒表、倒计时与番茄计时。任务、备注和计费状态由后台保存，
切换页面或关闭窗口不影响计时；暂停产生真实空档，番茄阶段结束后等待选择。

“自动标签”管理应用、文档与电脑使用的匹配条件。可测试当前日期，设置优先
顺序、排除时段、动态字段和前后追加；修改条件会重新计算过去日期。
正则捕获组可用于客户/项目等动态标签；临时工具使用可由邻近任务吸收，
短空档可按阈值填补。推断区间默认显示斜纹和“推断”，点明细可查看来源。
自动标签时间线的“转为标签…”保存当前结果，并明确选择重叠处理方式。
原生窗口、多条自动标签时间线等完整验收仍见功能对照。

## 工时表

日视图按最新反馈采用左侧汇总、右侧明细。应用、网站/文档和电脑使用的
汇总保留全天时长；选择应用后同时显示选中时长。Edge 可直接查看关联的
完整网址，切到应用明细可看窗口标题；切换时间线保留选择。旧采样的连续
片段合并显示，明细只渲染可见行。旧网站汇总缺少浏览器归属时明确单列。

点击应用名称查看相关记录；勾选框用于累加或扣除时间，可以跨应用、文档和电脑
使用组合选择。“全选”只添加或移除当前明细包含的时间，保留其他时间线的选择。
明细可按窗口标题（文档为网址/路径）、开始、结束和期间双向排序，排序保留选择。
按住 Command 或 Control 拖选可追加区间；取消拖选会恢复此前的选择。大量分散选区
按屏幕分辨率绘制，放大后恢复各段空档；统计、筛选、标签使用的仍是原始精确区间。

筛选支持 AND / OR、括号、前置减号排除、group / app / title / note 等字段、
时长和本地开始/结束时间比较、非空白通配符与 `#"…"` 正则。可点击筛选旁的问号
查看例子。表达式有误时保留上次结果和选区，在输入框旁说明未应用，修正后继续；
此时导出暂不可用，避免把旧结果误当作新筛选结果。跨日期高级搜索入口尚未实现。

左侧设置日期、来源、分组、计费/备注筛选与舍入，右侧显示按日期展开的矩阵。
单独第 N 级标签和前 N 级路径是不同分组。修改保留为草稿，生成后才替换结果；
导出捕获已生成的设置，CSV 与 Excel 使用同一矩阵。支持保存/载入选项，
保存日期范围需明确勾选；列排序随选项保存。

大字号下工具栏换行，表格在结果区内部滚动。浏览器下载的 Excel 已用独立
读取器对账。使用明细支持生成范围/所选行、三种活动时间线、合并/筛选、首次出现和局部改标；复制支持矩阵所选行或全部行、全部明细。QuickBooks 工作流与原生保存/复制的实际窗口验收仍待完成。


## 开发预览数据

交互预览及更新验收默认使用运行当天的真实统计独立副本：`python3 -B scripts/preview_today.py`。
启动时读取安装版当天的活动、标签、统计设置和已有截图；跨日片段裁剪到当天边界。
每次新一轮预览重新取快照，预览编辑只修改临时目录，不回写安装版，也不复制规则、锁定、安全词或管理凭据。
脚本不会启动拦截、记录或设备动作组件。测试窗口保留原有简洁界面，不新增常驻数据来源提示。


统计明细默认选择文档，以根域名合并全天访问并按期间从长到短排列。
“时序”按钮开启后，按开始时间排列，仅合并相邻且连续的同根域名访问；关闭后恢复全天合并及期间降序。
“详细”与“时序”使用同一切换按钮样式；“详细”保留逐次访问的完整地址。两种合并方式都使用实际访问区间计算期间和勾选范围，不把离开网站的空档算入。
汇总下拉菜单不提供文档。明细勾选框在首列水平、垂直居中。
时间轴“还原”恢复当天数据的适当可见范围；首个时间标签居中对准刻度线。
悬浮明细对应用名称、标题和网址去重，相同内容仅显示一次。


筛选应用汇总时，同时关联匹配网页/文件的实际所属应用；匹配文档可保留 Edge、Word 等拥有者，计时和勾选范围使用真实匹配区间。点击拥有者仍可保留文档筛选。
汇总与明细勾选框均为 14 像素，勾选框与图标、图标与文字之间均为 8 像素。
“还原”清空搜索、应用筛选和时间选择，再恢复时间范围；取消尚未完成的筛选请求，避免旧结果重新覆盖。
筛选用法按钮置于输入框内部最右侧；右下角不重复显示高级搜索、导出入口。
汇总底部始终显示选中时长与全天使用时长的比例；未勾选时为“0:00:00 / 全天使用时长”，筛选不会改变全天分母。
