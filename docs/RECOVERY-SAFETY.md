# 安全词输入修复与交付检查

2026-10-30，0.4.2 / Build 14 已安装。此前统计更新保留了旧执行器，未交付源码中已有的 AppKit 事件分发与输入可用性校验；因此不能用桌面版本号或源码测试证明本机执行器已经更新。

当前用户执行器会持续分发 AppKit 键盘、鼠标和输入法事件。设备动作前再次处理待发输入，并复核当前输入状态。后台只接受协议 2、与当前时段及动作匹配且仍新鲜的可用性回报；旧执行器或格式不符时不发送遮罩或设备动作。提交安全词的采样帧也不执行设备动作。应用拦截继续独立工作。

输入窗口持续失去焦点超过 2 秒时关闭本次遮罩，并在该时段拒绝继续限制；后台超过 5 秒不刷新则关闭窗口。系统可用性优先于维持一个无法输入的遮罩，不承诺抵抗管理员或利用失焦进行绕过。默认隐藏安全词，可通过“显示安全词”切换普通输入；切换保留文字和焦点，组合选字期间不允许设备动作。

原生检查仅使用窗口化、无设备动作代码的组件：实际 ASCII 键入及回车提交，AppKit 中文组合输入与提交，模式切换保留内容/焦点，持续失焦退出，以及后台失联退出。中文组合检查是组件检查，不等同于所有第三方输入法的人工实测；没有执行真实睡眠、锁屏、注销或关机循环。

打包 Python 3.13.17 通过 34 项当前用户安全词、后台传输、恢复范围和实际决策循环检查；测试后签名有效。安装只替换 `HotTurkeyAgent`、`device_blocks.py`、`platform_macos.py` 及安全协议状态字段。网站/应用规则、锁定、安全词、期限、已用额度、睡眠计划、统计功能及浏览器授权范围逐项核对保留，截图保持关闭。完整统计目标仍暂停，未发布开发中的高级搜索。

后续更新必须同时保留后台输入门槛与执行器协议，不能仅检查桌面包版本。核对运行中 `/api/state` 的 `enforcement.recovery_input_protocol == 2`，以及安装文件与已验证签名候选的哈希。普通安装器的锁定保护未改；本次用户要求直接修复，采用候选绑定、不可重放的状态保留安装事务。证据位于私有 `build/local-recovery-hotfix-proof.json` 和本次 `build/recovery-hotfix-*` 目录。
